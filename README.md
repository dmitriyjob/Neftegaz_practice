# Кластеризация скважин методом K-means

Учебный проект на Python: группировка **скважин**, выбор числа кластеров,
графики и автоматическая интерпретация на русском языке.
CSV может содержать повторные измерения: перед кластеризацией они агрегируются
медианой по `Well_ID`. На выходе каждой скважине соответствует ровно одна группа.

## Установка и запуск

Нужен **Python 3.11 или новее**; проверено на Python 3.12.

```bash
git clone https://github.com/dmitriyjob/Neftegaz_practice.git
cd Neftegaz_practice
python -m venv .venv
```

Активируйте окружение:

```bash
# Linux / macOS
source .venv/bin/activate
# Windows PowerShell
.venv\Scripts\Activate.ps1
```

Установите зависимости и запустите учебный пример:

```bash
python -m pip install -r requirements.txt
python cluster_wells.py --demo --output results/demo
```

Демонстрация генерирует 90 искусственных скважин с четырьмя измерениями каждой
и тремя заранее заложенными группами. Это проверка работы алгоритма,
а не доказательство существования трёх типов скважин в других данных.
`--seed` управляет кластеризацией; набор демонстрационных данных фиксирован (seed=42).

## Анализ Oil_Gas.csv

Поместите свой CSV в каталог `data/` (создайте его при необходимости):

```bash
python cluster_wells.py --input data/Oil_Gas.csv --output results/oil_gas
```

Откройте `results/oil_gas/report.md`: в нём таблицы, графики и интерпретация.
Исходные пользовательские данные и результаты исключены из Git через `.gitignore`.
Репозиторий не содержит загруженный пользователем CSV или его производные.
Повторный запуск в тот же каталог обновляет файлы результатов.

## Входные данные и единицы измерения

Обязателен непустой `Well_ID` — глобально уникальный идентификатор скважины.
Необязательные `Timestamp` и `Field_ID` используются только для проверки и метаданных.
Если `Timestamp` есть, даты должны быть корректными, пары `Well_ID` / `Timestamp` — уникальными.
При нескольких измерениях одной скважины используются медианы за **весь период**.
Для сравнения текущих режимов заранее ограничьте CSV общим временным окном.

Признаки по умолчанию:

| Столбец | Смысл | Единицы |
| --- | --- | --- |
| `Depth_m` | Глубина | м |
| `Reservoir_Pressure_MPa` | Пластовое давление | МПа |
| `Porosity_pct` | Пористость | % |
| `Permeability_mD` | Проницаемость | мД |
| `Net_Pay_m` | Эффективная нефтенасыщенная толщина | м |
| `Oil_Rate_bpd` | Дебит нефти | барр./сут |
| `Gas_Rate_Mscf_d` | Дебит газа | тыс. стандартных куб. футов/сут |
| `Water_Cut_pct` | Обводнённость | % |

Единицы предполагаются по именам столбцов; их нужно сверить с описанием источника.
Другие числовые признаки можно выбрать явно:

```bash
python cluster_wells.py --input data/Oil_Gas.csv --features Porosity_pct Permeability_mD Net_Pay_m Oil_Rate_bpd Water_Cut_pct --max-k 6 --output results/alternative
```

`Well_ID`, `Field_ID`, `Timestamp` и `Future_*` запрещены в качестве признаков.
Для CSV с разделителем `;` и десятичной запятой добавьте `--sep ";" --decimal ","`.
Пустые значения допустимы; текст в числовых столбцах и бесконечности отклоняются.
Известные физические признаки проверяются на неотрицательность, проценты — на диапазон 0–100.
Это базовая проверка формата, а не полноценный контроль качества промысловых данных.

## Алгоритм

1. Проверка входных данных и медианная агрегация по скважине.
2. Заполнение оставшихся пропусков медианами по скважинам (`SimpleImputer`).
   Скважины без единого наблюдаемого признака и полностью пустые признаки отклоняются.
3. `log1p` для проницаемости, исключение постоянных признаков, `StandardScaler`.
   Требуются минимум три скважины и два непостоянных признака.
4. `KMeans(n_init=20, random_state=42)` для k от 2 до 8. Верхняя граница
   ограничена числом скважин минус один и числом различных профилей.
5. Выбор k с максимальным коэффициентом силуэта; график инерции для метода локтя.
6. Профили групп в исходных единицах, PCA в двух измерениях и тепловая карта.
7. Проверка устойчивости к трём другим seed с помощью Adjusted Rand Index (ARI).

Кластеризация выполняется по всем выбранным непостоянным признакам, **не по PCA**.
Номера кластеров упорядочены по среднему дебиту нефти (или первому выбранному признаку,
если дебит не включён), начиная с 1. Номера не имеют самостоятельного физического смысла.
Силуэт вычисляется по всем скважинам и требует квадратичного времени; код ориентирован
на учебные выборки из десятков или сотен скважин, а не на миллионы объектов.

## Как интерпретировать

Сравнивайте профили кластеров и размер каждой группы. Например, группа с относительно
высокими дебитом и проницаемостью отличается по этим характеристикам от остальных,
но это само по себе не доказывает причину высокой добычи.
Отчёт выделяет признаки, отстоящие от среднего не менее чем на 0,5 стандартного
отклонения: это описательный порог, а не статистический тест.

Силуэт около нуля означает сильное перекрытие. При силуэте ниже 0,25 отчёт явно
отмечает слабое разделение; порог ориентировочный. Максимум среди k ≥ 2
**не доказывает**, что данные вообще имеют естественные кластеры.
ARI проверяет только чувствительность к инициализации. Для практических выводов
нужны проверки на разных периодах и наборах признаков, учёт корреляций и выбросов.
Медиана за длительный период скрывает изменение режима работы скважины.

## Проверки

```bash
python -m unittest discover -s tests -v
```

Проверяются восстановление известных синтетических групп, агрегация повторных
измерений, обработка пропусков, исключение будущих показателей, воспроизводимость,
некорректные входные данные и сохранение отчёта с графиками.
