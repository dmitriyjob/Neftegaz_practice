# Кластеризация нефтяных скважин по открытым данным BOEM

Реферат по теме 9 «Кластеризация данных»
Предмет «Анализ данных в нефтегазе 26/27»

## 1 Задача и основные методы

В работе скважины группируются по показателям добычи за 2023 год (январь–декабрь). После отбора осталось 1 387 скважин. Для K-means выбрано число групп k=2. Средний коэффициент силуэта равен 0,412. Практическая задача состоит в том, чтобы найти скважины с похожими эксплуатационными характеристиками и определить, какие дополнительные данные нужны для проверки различий между группами.

Кластеризация относится к обучению без учителя: готовых меток типов скважин в исходных данных нет. Близость определяется выбранными признаками и расстоянием между их значениями. Поэтому один фонд можно разделить по-разному, если изучать геологию, добычу или техническое состояние оборудования. В этом примере рассматривается эксплуатационный профиль [2].

K-means относит каждый объект к ближайшему центру и пересчитывает центры как средние значения признаков. Число групп k задаётся до обучения. Метод удобен для компактных групп скважин по дебиту, обводнённости и газовому фактору. Он чувствителен к масштабу признаков и выбросам, а группы сложной формы может описывать плохо [2].

J = Σⱼ₌₁ᵏ Σᵢ∈Cⱼ ‖zᵢ − μⱼ‖² → min

Здесь zᵢ обозначает преобразованный вектор признаков скважины i, Cⱼ соответствует кластеру j, а μⱼ является его центром. Минимизируется сумма квадратов евклидовых расстояний до центров. Алгоритм повторяет назначение объектов и пересчёт центров до сходимости. Он может прийти к локальному минимуму, поэтому используются разные начальные центры.

Иерархическая кластеризация Ward последовательно объединяет группы с минимальным приростом внутригрупповой суммы квадратов. Дендрограмма позволяет рассматривать фонд с разной детализацией, например разделить общую группу обводнённых скважин на подгруппы. Для крупных выборок такой расчёт требует больше памяти. Ward также зависит от масштаба признаков [3].

DBSCAN объединяет соседние объекты в плотных областях, а изолированные точки помечает как шум. Это полезно для поиска необычных режимов скважин. Число групп заранее не задаётся, но необходимо выбрать радиус соседства eps и минимальную численность окрестности min_samples, включая сам объект. Разная плотность групп осложняет подбор параметров [4].

Смесь гауссовых распределений GMM описывает данные несколькими вероятностными компонентами и оценивает вероятность принадлежности скважины каждой из них в рамках модели. Так можно показать неопределённость для переходных режимов. Модель допускает эллипсоидальные группы, но зависит от предположений о распределениях и числе компонент [5].

## 2 Открытые данные и подготовка признаков

Источник: BOEM OGOR-A 2023 [1]. Период анализа: 2023 год (январь–декабрь). Исходный набор содержит 74 986 строк и 5 992 уникальных идентификаторов скважин. Опубликованные сведения о добыче позволяют проверить расчёты и повторить отбор. Используется сохранённая копия выгрузки, поскольку исходная публикация может обновляться. BOEM разрешает копирование публичной информации с указанием источника, но не гарантирует полноту и безошибочность данных [11].

Единица анализа соответствует стволу скважины с 12-значным номером API, который включает код бокового ствола. Исходная запись описывает месяц работы объекта эксплуатации (completion). Записи объединяются в годовой профиль API. Сам идентификатор не участвует в вычислении расстояний [9].

| Условие отбора | API до | API после |
| --- | --- | --- |
| Все API | 5 992 | 5 992 |
| Есть добыча нефти | 5 992 | 2 208 |
| Только нефтяной код O | 2 208 | 1 797 |
| Нефтедобывающий статус | 1 797 | 1 797 |
| 12 месяцев отчётности | 1 797 | 1 756 |
| Один активный completion | 1 756 | 1 688 |
| Без пересечения дней | 1 688 | 1 688 |
| Нефть минимум 9 месяцев | 1 688 | 1 388 |
| Без закачки | 1 388 | 1 387 |

После отбора в анализ включены 1 387 скважин и 17 425 исходных строк. Единственный активный объект эксплуатации исключает двойной счёт дней работы при параллельной добыче. Фильтры ограничивают выводы регулярно работающим нефтяным фондом. Каждая скважина имеет одинаковый вес при обучении независимо от объёма добычи.

Стволы с ненулевой зарегистрированной закачкой исключены: Days Produced может учитывать дни закачки. Для газлифтных скважин инструкция требует указывать пластовый газ за вычетом газа, поданного на газлифт, поэтому высокий GOR нельзя объяснять прямым включением газлифтного газа в добычу [10].

| Признак | Расчёт и единицы |
| --- | --- |
| Дебит нефти | Σ нефть / Σ дни работы. барр./сут работы |
| Обводнённость | 100 × Σ вода / (Σ нефть + Σ вода). % |
| Газовый фактор | 1000 × Σ газ (Mcf) / Σ нефть (bbl). станд. куб. фут/барр. |

Нефтяной дебит и газовый фактор преобразуются функцией log(1+x), которая сжимает большой диапазон значений. Затем все признаки стандартизируются: из каждого значения вычитается среднее по скважинам, результат делится на стандартное отклонение. Так признак с численно большим масштабом не получает преимущество только из-за единиц измерения. При этом StandardScaler не устраняет влияние выбросов [6].

## 3 Выбор числа групп и результаты

Проверены значения k от 2 до 8. Для каждого выполняются 20 инициализаций K-means при random_state=42. Из них берётся запуск с минимальной инерцией, то есть целевой суммой квадратов. Затем значения k сравниваются по среднему силуэту и выбирается его максимум. Для отдельной скважины s=(b−a)/max(a,b), где a является средним расстоянием до остальных объектов своей группы, а b является наименьшим средним расстоянием до объектов другого кластера. Значения около нуля указывают на перекрытие, отрицательные значения требуют проверки назначения [7].

По выбранному критерию получено k=2, силуэт равен 0,412. Профили групп описаны медианами исходных характеристик входящих в них скважин. Они выражены в физических единицах и отличаются от центров K-means в преобразованном пространстве.

| Группа | Скважин | Нефть барр./сут работы | Вода % | GOR scf/bbl |
| --- | --- | --- | --- | --- |
| 1 | 846 | 51,9 | 85,0 | 1 121 |
| 2 | 541 | 1 592,1 | 12,6 | 872 |

У 0,7% скважин индивидуальный силуэт отрицателен: по выбранным расстояниям они в среднем ближе к соседней группе. При дальнейшем изучении фонда такие пограничные назначения стоит проверять отдельно.

Для каждой группы выбран ближайший к её центру объект в пространстве модели. Значения относятся к этим скважинам, а не ко всей группе.

| Идентификатор | Группа | Нефть барр./сут работы | Вода % | GOR scf/bbl |
| --- | --- | --- | --- | --- |
| 608174094300 | 1 | 47,6 | 77,2 | 1 199 |
| 608184004403 | 2 | 1 045,0 | 25,7 | 760 |

Группы прежде всего различаются дебитом нефти и обводнённостью. При исключении GOR состав меняется мало: ARI=0,943. Для группы 1 с наибольшей медианной обводнённостью полезно проверить динамику поступления воды и ограничения оборудования по обработке жидкости. Группа 2 с наибольшим медианным дебитом нефти подходит для подбора эксплуатационных аналогов при сопоставимых условиях.

Из кластеризации нельзя установить причину обводнения или рассчитать эффект ремонта. Для этого потребуются история работы, конструкция скважины, свойства пласта и результаты исследований. Номера групп условны и не являются оценкой качества скважин.

Две компоненты PCA сохраняют 88,6% дисперсии преобразованных признаков. PCA применяется только для изображения скважин на плоскости. Само разбиение рассчитано по всем выбранным признакам.

## 4 Устойчивость и ограничения выводов

При смене начальных состояний ARI равен 1,000 во всех проверенных запусках. ARI сравнивает назначения объектов с поправкой на случайное совпадение и не зависит от нумерации кластеров. Значение 1 соответствует одинаковому разбиению. Такая проверка показывает чувствительность к инициализации, но сама по себе не подтверждает геологическую природу групп [8].

При том же числе групп метод Ward даёт силуэт 0,361 и ARI 0,574 относительно K-means.

При повторном анализе подвыборок медиана ARI составляет 0,986, диапазон 0,968…0,996. Масштабирование и модель обучаются заново, сравнение выполняется на общих объектах.

RobustScaler: ARI=0,211. Те же признаки и log1p; масштабирование по медиане и IQR, k фиксировано.

Без log1p: ARI=0,684. Те же признаки; StandardScaler, k фиксировано.

Без газового фактора: ARI=0,943. Дебит и обводнённость, log1p дебита; k фиксировано.

Первое и второе полугодия: ARI=0,839. 1387 общих API с добычей нефти ≥3 месяцев в каждом полугодии; scaler и K-means обучены отдельно, k фиксировано.

Отбор ограничен нефтяными стволами с регулярной добычей в 2023 году; выводы не распространяются на весь фонд BOEM.

API включает боковой ствол. Скважины одного месторождения связаны общими условиями; 1387 объектов нельзя автоматически считать независимой случайной выборкой.

Дебит и газовый фактор имеют общий нефтяной объём в формулах. Корреляции и масштабирование влияют на геометрию групп.

Годовые показатели скрывают динамику. Сравнение полугодий совмещает реальное изменение режима и чувствительность модели.

В данных нет пластового давления, проницаемости, затрат и причин изменения режима. Кластеры не доказывают геологическую причинность или выгоду ремонта.

Максимум силуэта среди k≥2 не является проверкой существования естественных кластеров. ARI не является точностью без эталонной разметки.

При фиксированной подготовке данных группы устойчивы к инициализации и проверенным подвыборкам. Замена StandardScaler на RobustScaler существенно меняет назначения: ARI=0,211. Поэтому результат описывает выбранный фонд в рамках этой методики. Он помогает искать эксплуатационные аналоги и выбирать объекты для проверки, но не устанавливает универсальные типы скважин.

Повторить расчёт из корня репозитория: python run_analysis.py. Паспорт исходных данных и полные таблицы отбора находятся в data/boem, результаты и параметры запуска сохраняются в results/boem_2023.
